## Generator and safety

Run from this worktree: `python3 tools/audio/elevenlabs_generate.py` (dry-run, no key needed). Selecting jobs: `python3 tools/audio/elevenlabs_generate.py --ids tick fan`. Actual requests require --go, explicit --ids, and ELEVENLABS_API_KEY in the environment. Voice requests additionally require --voice-id. Do not use --go during prep. No credential files are read, no keys are logged, no automatic retries after uncertain outcomes. Live batches hold a nonblocking Office Mac file lock to prevent overlapping requests; the persistent .generation.lock is not audio. Outputs stay under docs/audio/generated; existing files are skipped. A zero-byte existing output is an error, not a successful skip.

Official docs consulted: [Sound generation](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert), [Text to speech](https://elevenlabs.io/docs/api-reference/text-to-speech/convert). Uses POST /v1/sound-generation, loop, duration_seconds (0.5–30), eleven_text_to_sound_v2; TTS uses POST /v1/text-to-speech/{voice_id}, eleven_multilingual_v2. No credit estimate is supplied. No account, quota or secret lookup was performed.
