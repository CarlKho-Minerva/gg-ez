# Sound credits

All thirteen clips in this folder were generated with ElevenLabs Sound Effects on 2026-10-28 from text prompts written for this game (swing, whiff, hit, blast, ko, chat, type, queue, smash, phone, room, crt, street). ElevenLabs' terms allow their use in a published game. The earlier free-pack placeholders are kept in `assets/sfx_old/` and are no longer loaded.
